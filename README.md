# 🎓 مدرس الآيلتس (IELTS Coach)

موقع شخصي ومجاني تذاكر بيه IELTS (Academic أو General). فيه مدرس AI بيتكلم معاك بالعامية المصرية، دمه خفيف، وبيصحح كل غلطة.

## فيه إيه؟
- ✍️ **Writing Task 2** و 📊 **Writing Task 1**: يديك سؤال، تكتب، فيصححلك كل غلطة ويديك band ونسخة أحسن. وبعدها تقدر تناقشه.
- 🎤 **Speaking**: ممتحن بيتكلم إنجليزي بصوت. تجاوب بالمايك أو بالكتابة، وفي الآخر يقولك غلطاتك.
- 📖 **Reading** و 🎧 **Listening**: تمارين جديدة كل مرة بتتصحح على طول، والـ Listening بيتقري بصوت.
- 💬 **دردش مع المدرس**: اسأل أي حاجة.
- 📒 **كشكول الأخطاء**: كل غلطة بتتحفظ، وفيه زرار "اختبرني فيهم".
- 📈 **تقدّمي**: درجاتك في كل مهارة.

## 1) هات مفتاح Gemini المجاني
1. افتح https://aistudio.google.com/apikey وسجّل بحساب جوجل.
2. دوس **Create API key** وانسخ المفتاح.
3. افتح الموقع وروح ⚙️ **الإعدادات**، والزق المفتاح، ودوس **حفظ**.

> المفتاح بيتحفظ على جهازك بس. ولو ظهرتلك رسالة إن "الحد المجاني خلص"، استنى شوية أو كمّل بكرة.
> ولو جوجل غيرت أسماء الموديلات، غيّر اسم الموديل من الإعدادات (مثلًا `gemini-flash-lite-latest`).

## 2) ارفع الموقع ببلاش وافتحه من الموبايل

**أسهل طريقة: Netlify Drop**
1. نزّل فولدر المشروع ده على الكمبيوتر.
2. افتح https://app.netlify.com/drop واسحب الفولدر جوه الصفحة.
3. هياخد لينك. افتحه من الموبايل، ومن Safari دوس **Share → Add to Home Screen** عشان يبقى زي الأبلكيشن.

**أو GitHub Pages**
1. ارفع الملفات على repository في GitHub.
2. ادخل Settings → Pages → Branch: `main` → Save.

## للمطورين
- مفيش build: ملفات HTML/CSS/JS عادية.
- تشغيل محلي: `npm run serve` وبعدين افتح `http://localhost:8080`.
- اختبارات: `npm test` (unit) و `npm run e2e` (Playwright، والـ AI فيها متقلّد).
